## Practical limits

- Browser drafts live in that tab's session storage, not on a second computer. Save edits to the studio for durable server storage. Closing the tab or clearing browser storage can remove an unsaved draft.
- The app supplies two text prompts. Actual anchor/newsroom references, image/voice generation, animation tooling and rendering must exist in the downstream Claude workflow.
- News-feed collection and automated warnings do not establish truth, independence or a commercial content licence.
- The local SQLite workflow is tested. Managed PostgreSQL, container execution, cloud networking and a real scheduled Azure run require environment-level validation before production use.
